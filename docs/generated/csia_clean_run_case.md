## B. Minimal case

The frozen adapter fed three inputs only (rotor speed, iq, p_dc), held constant and simultaneous for 3 s at two steady operating points of the same simulated vehicle. With constant simultaneous inputs no timing effect is possible.

| Point | Rotor [rad/s] | DC current [A] | iq (fixture) [A] | p_dc [W] | E6 lambda, default kt 0.06 | Explanation | kt that balances E6 [N m/A] |
|---|---|---|---|---|---|---|---|
| cruise 6.5 m/s | 272.3 | 0.653 | 0.588 | 32.84 | 15.98 | DISAGREE_AMBIGUOUS | 0.173 |
| cruise 4.0 m/s | 167.6 | 0.379 | 0.341 | 19.06 | 7.93 | REGIME_GATED | 0.260 |

The torque constants that balance the two points exactly differ (0.173 and 0.260 N m/A): with the fixture's iq the balancing value goes as v_bus / (0.9 x rotor speed), so it changes with speed, which a motor's torque constant does not. Within E6's tolerance the difference is hidden: with 0.173 the 4.0 m/s point gives lambda 1.22 (REGIME_GATED). Fitting kt to this data would therefore mask the input mismatch, not resolve it, and it would be tuning; it is not done.

## C. Cause

* **Relationship:** E6 power balance only. E1, E2, E3a, E3b and E7 stay far below their threshold on the same run.
* **Admissible inputs:** p_dc (ctrl.dc_voltage x ctrl.dc_current, aligned within 20 ms), iq (ctrl.phase_current_q), rotor (ctrl.motor_speed), all from the semmc fixture's 100 Hz frames.
* **Timing:** not the cause: the minimal case uses constant, simultaneous inputs and fails the same way.
* **Operating context:** the failures are at the higher steady speed and in transients with power; at 4.0 m/s steady the residual stays under the threshold.
* **Model assumptions:** E6 expects p_dc = (1 + 0.08) x kt x iq x rotor + 3 W, with iq the motor's q-axis current and kt the motor's torque constant. The boundary gave no kt (the motor data are open, B-MOTOR), so the adapter used its default 0.06 N m/A; and the simulation fixture's `ctrl_motion.iq_A` is 0.9 x the DC current, an illustrative field, not a current consistent with any torque.
* **Classification:** an adapter input mismatch in an unsupported configuration: a required parameter defaulted and an input whose meaning differs from the relationship's model. Not a timing defect. Not shown to be a limitation of the CSIA algorithm: the case says nothing about E6 with a real motor's kt and a real q-axis current.
