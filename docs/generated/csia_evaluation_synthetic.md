# CSIA held-out evaluation and ablation - SYNTHETIC

> Synthetic sensors, synthetic faults, shadow mode. **Not vehicle evidence.** Generated by `tools/run_csia_evaluation.py`; protocol in `docs/csia/EVALUATION_PROTOCOL.md`. The adapter, the development generator, the baselines and this harness were frozen before the evaluation set was run (`docs/csia/DEV_SET_FREEZE.json`).

Held-out set: 94 scenarios (24 fault-free, 70 with one fault each), 5.80 h of operation outside fault windows (2.00 h in fault-free scenarios). Unseen seeds; randomised pulse bands, standing starts after stops, long coasts, hills of ±2.5 %, corners, GNSS degradation and outages; faults with random onset, duration and magnitude, including drifts, dropouts and kinds absent from the development set.

Definitions: an alarm is any reported problem (attributed or ambiguous). A false alarm is an alarm episode outside a fault window [onset, end + 5 s]. Detection = an alarm implicating the faulty node inside the window. Attribution = that node named alone as the suspect. Misattribution = any other node named as suspect inside the window. Eligible = at least one relationship involving the faulty node passes the frozen adapter's regime gates with fresh inputs. Unobservable = time inside the fault with no eligible relationship for that node, during which no relationship-based method can see the fault.
