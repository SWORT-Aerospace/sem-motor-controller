# Documentation index

Every file in `docs/`, grouped by what it is for. **Current** documents describe the repository as it is and are kept up to date (their links and file paths are checked by `tools/check_links.py`). **Historical** records describe an earlier release and are kept unchanged as evidence; **superseded** ones name their replacement. Generated files are rewritten by the tool named; edit the source, not the file.

Start with the [README](../README.md), then this page. Files outside `docs/`: [`FILE_INDEX.md`](FILE_INDEX.md).

## 1. Current guides

**Scope (v0.7).** The deliverable is the telematics unit and the pit software; the motor controller is built by another team ([`decisions/ADR-0013-telematics-scope.md`](decisions/ADR-0013-telematics-scope.md)). Section 1.1 is the telematics delivery; section 1.2 keeps our earlier controller design as deferred controller development, current but not on the telematics path. Which suite each file belongs to: [`scope.yaml`](scope.yaml), rendered as [`generated/scope.md`](generated/scope.md) by `tools/scope.py`.
